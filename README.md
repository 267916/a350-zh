# iniBuilds A350 座舱与 EFB 中文

把 iniBuilds A350 的**座舱提示**和**两块 EFB 平板**显示为中文。

**本仓库不包含 A350 的任何文件。**

---

## 这是什么

分两部分。

### 一、座舱汉化

A350 的座舱提示文字存放在机模的语言文件（`.locPak`）里。本工具按英文原文替换其中的内容，因此：

- 只改语言文件，不动模型、贴图、程序代码
- 原文件自动备份，可完整还原
- iniBuilds 更新覆盖之后，重新运行一次即可恢复

### 二、EFB 平板中文层

两块 EFB 平板的文字是硬编码在程序里的，没有语言文件可用。本工具**不修改那个程序**，而是在 EFB 页面上挂一个独立的渲染层脚本，只替换显示出来的文字：

- EFB 的逻辑一行不动，因此不会影响功能
- 附带一个 **中 / EN 切换按钮**（EFB 右下角），选择会被记住
- 卸载时原地移除，字节级可逆

## 操作说明

### 使用

1. 把本仓库的文件解压到**同一个文件夹**
2. 双击 `A350座舱中文.exe`
3. 程序会自动找到 Community 文件夹里的 A350 并完成汉化

### 官方更新之后

iniBuilds 每次更新会覆盖语言文件，汉化会消失。**重新双击一次本程序即可。**

不确定当前状态时，先运行 `查看状态.cmd`。

### EFB 语言切换

两块 EFB 平板右下角有一个圆形按钮：

- 显示「**中**」= 当前中文，点一下切英文
- 显示「**EN**」= 当前英文，点一下切回中文

选择会记住，下次打开 EFB 保持。

### 命令

| 操作 | 说明 |
|---|---|
| 双击 `A350座舱中文.exe` | 应用汉化（可重复运行，无副作用） |
| `查看状态.cmd` | 查看当前汉化状态 |
| `还原英文.cmd` | 完全卸载，还原英文原版 |

### 覆盖范围

座舱 **3638 / 3966 条（91.9%）**，其中悬停说明 99.7%、检查单 96.4%。

未翻译的部分是有意保留的：键盘字母、数字、方向符号，以及航空标准缩略语（`APU`、`ADIRS`、`A/THR`、`VHF1`、`VOR1` 等 —— 它们必须与面板和检查单保持一致）。机库里的飞机简介由官方提供中文，未重复翻译。

EFB 约 230 条词典，另有后缀规则自动处理大量变体（如 `XXX FAULT` → `XXX 故障`）。

### 前提条件

| 条件 | 不满足会怎样 |
|---|---|
| A350 装在 **Community 文件夹**里 | Marketplace 版可能定位不到 |
| A350 以**普通用户身份**运行 | 若它提权运行，可能会失效 |
| 系统有中文字体 | 无中文字体会显示方框 |

### 自定义词表

所有 `*对照.txt` 都是 `英文=中文` 格式，`#` 开头为注释：

| 文件 | 内容 |
|---|---|
| `值对照.txt` | 通用短词（按下 / 开 / 关 …） |
| `面板对照.txt` | 面板开关名 |
| `说明句对照.txt` | 悬停说明句 |
| `检查单对照.txt` | 检查单与状态值 |
| `补充对照.txt` | 补充条目 |
| `键对照.txt` | 按完整键名匹配（优先级最高） |
| `efb对照.txt` | EFB 界面词 |

改完重新运行一次程序即生效，**不需要重新编译**。**UTF-8 与 ANSI/GBK 都能正确读取**，用记事本随手保存即可。

### 自行编译

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe ^
  /nologo /target:exe /codepage:65001 /out:A350座舱中文.exe A350CockpitZh.cs
```

> `A350CockpitZh.cs` 必须存为 **UTF-8 带 BOM**，否则编译器会把中文读成乱码。
